# Solar Mix Balance for Home Assistant

**[Deutsch](README.de.md) | [English](README.en.md)**

Independent Home Assistant custom integration for monitoring solar energy, home consumption, battery charge/discharge, grid import, self-consumption, self-sufficiency, and historical costs. It works locally with user-selected entities from systems such as Zendure, EcoFlow, and grid energy meters.

**Original project / Urheber:** Marcel Lörz, GitHub [0ver0n](https://github.com/0ver0n), https://www.blindmitwomo.com. **License:** [Apache License 2.0](LICENSE), [NOTICE](NOTICE).

**Version:** 5.8.2, installed and successfully restarted on the author's Home Assistant Core 2026.10.1 (7 November 2026). The existing 172 sensor entities, historic data files, configuration and all five actions remained available. **Open-source release:** https://github.com/0ver0n/smartwomo/tree/main/solar-mix-balance.

Source: `custom_components/solar_mix_balance/`. [German installation](INSTALLATION.de.md) | [English installation](INSTALLATION.en.md).

No energy or account data is included. Home Assistant stores its own readings and price archives locally. Keep this data private; do not upload live CSV archives or HA database files to public repositories.
