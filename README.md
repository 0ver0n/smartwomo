# smartwomo

**Deutsch:** Freie, unabhängige Werkzeuge für Wohnmobil, Batterietechnik und Home Assistant. Entwickelt von **Marcel Lörz** · https://www.blindmitwomo.com.

**English:** Free, independent motorhome and Home Assistant tools. Created by **Marcel Lörz** · https://www.blindmitwomo.com.

## Projekte / Projects

- [Truma LevelControl BLE](truma-levelcontrol/README.md): Bluetooth-based local Home Assistant integration. **A specific 11 kg steel cylinder is the calibrated default.** Different cylinder sizes require changing the geometry profile and verifying readings. [Deutsch](truma-levelcontrol/README.de.md) · [English](truma-levelcontrol/README.en.md).
- [Victron SmartShunt VE.Direct / MQTT](victron-smartshunt/README.md): Home Assistant add-on with battery telemetry and optional HEX commands. **v4.2.3 is security-hardened and offline-tested; the privilege changes have not yet been validated on physical USB hardware.** [Deutsch](victron-smartshunt/README.de.md) · [English](victron-smartshunt/README.en.md).
