# Truma LevelControl BLE for Home Assistant

**[Deutsch](README.de.md) · [English](README.en.md)**

Open-source Home Assistant Bluetooth integration to monitor Truma LevelControl devices locally, without a cloud service.

**Author / Projektinitiator:** Marcel Lörz ([0ver0n](https://github.com/0ver0n)) · **Blog:** https://www.blindmitwomo.com

**Version:** 0.3.0 · **License:** [Apache License 2.0](LICENSE) · [Attribution](NOTICE).

**Read before installation:** The fill-level curve is calibrated for a specific German **11 kg steel cylinder**. With other bottle types, you **must adapt the profile** and validate against the manufacturer app. See [Gasflaschen anpassen / Customize cylinder profiles](FLASCHENPROFILE.de.md) and [Cylinder profiles (English)](CYLINDER-PROFILES.en.md).

[Installation Deutsch](INSTALLATION.de.md) · [English installation](INSTALLATION.en.md)

No official affiliation with Truma. Results are informational; never use them as a gas safety system. Local BLE access and a supported Home Assistant Bluetooth adapter required.
